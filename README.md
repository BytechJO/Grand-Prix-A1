# Grand Prix A1

Interactive French Unit 1, adapted from Right-G1 while retaining the PMAA / Preiss Murphy visual identity.

- Student Book pages 4–25 and Workbook pages 4–9.
- 70 activities with checking, answers, retry and local progress storage.
- 13 prerecorded audio tracks with word-level highlighting.
- Original cover, activity-only popups and cropped page displays without printer marks.
- Teacher Book and answer-key references.

## Run locally

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

## Validate and build

```sh
npm run test:unit1
npm run lint:unit1
npm run build
```

See GRAND-PRIX-NOTES.txt for asset generation and audio alignment details.
The legacy Right code and assets are retained in this independent copy. Changes to this repository do not update Right-G1.
